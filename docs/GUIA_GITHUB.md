# Cómo subir este proyecto a GitHub (sin experiencia previa)

## Opción fácil (sin terminal)
1. Crea una cuenta en https://github.com
2. Pulsa **New repository** → nombre: `analisis-inditex` → público → **Create repository**.
3. Pulsa **uploading an existing file** y arrastra todo el contenido de esta carpeta.
4. Escribe un mensaje (p. ej. "Estructura inicial") y pulsa **Commit changes**.

## Opción recomendada (GitHub Desktop)
1. Instala https://desktop.github.com e inicia sesión.
2. File → **Add local repository** → elige esta carpeta → "create a repository".
3. **Publish repository**. Cada vez que avances: escribe un mensaje y pulsa **Commit** + **Push**.

## Consejos
- Haz commits pequeños y frecuentes con mensajes claros ("Añade ratios 2022-2025").
- Crea también un repositorio con tu nombre de usuario exacto: su README será tu página de perfil.
- Antes de compartirlo, revisa que el README principal se entienda sin abrir ningún otro archivo.
